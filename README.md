# FGUHub

This repository is organized around a simple safe workflow:

- `Workshop` is the working branch where new ideas, edits, and experiments happen.
- `main` is the final branch and should only contain approved, stable changes.

## Workflow

1. Switch to `Workshop` before making changes.
2. Test and review changes in `Workshop`.
3. Commit finished work to `Workshop`.
4. Merge into `main` only when the work is ready to become the final product.

## Git Notes

- `origin` points to `https://github.com/Hoangthomasn/FGUHub.git`
- `workshop` points to the older `FGU-Workshop` remote
